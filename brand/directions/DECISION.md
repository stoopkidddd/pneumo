# Brand decision

- **Date:** 2026-10-31
- **Issue:** ENG-233
- **Decided by:** the owner, from the review page (`brand/directions/index.html`)

## Choice

A mix: **A's mark** with **B's palette and type**.

| Element | Source | Details |
| -- | -- | -- |
| Mark (app icon, favicon, notification icon) | A / Dispatch | The ribbed mail capsule with a forward lean and two motion bars (`a/mark.svg`). |
| Palette | B / Switchboard | Light and dark token sets from `b/direction.json`. Accent is signal blue: `#1947C7` light, `#8CA9FF` dark. |
| Type | B / Switchboard | Chivo 600 for display, Public Sans 400 for UI. Both OFL. |
| Wordmark | B / Switchboard | Lowercase "pneumo" set in Chivo (`b/wordmark.svg`), to match the chosen type. |
| Lockup | Mix | A's mark beside B's wordmark. |

The owner's words: "B's color scheme and font with A's icon/logo". The owner chose B's fonts, so the lead read "icon/logo" as A's mark and kept B's Chivo wordmark beside it. If the owner wants A's condensed uppercase wordmark instead, ENG-241 changes the wordmark only.

## Notes for the finalize issue (ENG-241)

- Check A's mark against B's palette:
  - The mark on the accent surface needs at least 3:1 contrast.
  - `onAccent` must stay readable on the accent.
  - The monochrome notification silhouette must still read at 24 dp.
- A's mark carries the "pneumatic mail" story, so B's P monogram is dropped.
- A's red palette and Barlow fonts are not used.
